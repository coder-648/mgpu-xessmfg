# lock_frame 1.2.0 发布说明

**这次的 1.2.0 是把客户端真正做成"小白能用"的一版。**

## 打包变化

- **默认自带 Intel 运行时**：`libxess_fg.dll`、`libxell.dll` 已放进压缩包
  （附 `INTEL-XESS-LICENSE.txt`），解压即用，不用再去 Intel 官网找 DLL。
- 想要精简包可以自行删除这两个 DLL（2x 只依赖 `libxess_fg.dll`，
  3x/4x 还需要 `libxell.dll`）。

## 交互重做

- **一个游戏 = 一份配置**：选中游戏后，倍率/输入源/MV 比例/高级参数全部属于它，
  改动即时保存；切换游戏自动切配置。
- 每份配置单独存成 `profiles\<游戏名>.ini`，主 `lock_frame_ui.ini` 只保存索引；
  旧版本的内联配置首次启动会自动迁移。
- **选择游戏只有一个入口**：当前游戏卡片右上角（未选=「选择游戏」，已选=「更换游戏」）。
- **游戏库 = 选择器**：只做「添加 exe… / 点一行选中」；不再批量扫描整机游戏库。
- **安装/还原/主程序/高级设置** 收进同一行；安装=把当前配置写进游戏目录的
  `fakerFG.ini`，还原=移除组件。
- 新增**运行中拦截**：游戏在跑（含最小化到托盘）时不允许安装/还原；
  `fakerFG.ini` 被外部改动会提示“重新应用配置”。
- 支持**点击游戏名重命名**，配置文件会跟着改名（自动命名的情况）。
- 窗口 1240×720 逻辑坐标，字体整体放大；运行状态改成 5 个 KPI；
  右上角提供「高级设置」抽屉；中/英双语、UIA 读屏、DPI 缩放继续保留。

## 兼容性

- 共享协议仍为 **v28**，游戏侧 `fakerFG.dll` / `xess_mfg_producer.dll` 必须与
  本包同版本。
- 支持 Windows 10 1903+ / Windows 11，D3D12；建议双显卡、游戏无边框 + 开启
  DLSS 帧生成。
- 仅单机/离线使用；不要在带反作弊的在线游戏里使用。

## 已知限制

- 全局扫描（Steam/Epic/GOG/注册表批量导入）暂时从界面下线，改为手动添加 exe。
- 中文重命名依赖输入法提交字符（没有 IME 候选框浮层）。
- 没有“删除游戏配置”按钮（可直接删 `profiles\*.ini` 后重启 UI）。
