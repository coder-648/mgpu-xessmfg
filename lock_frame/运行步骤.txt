﻿﻿﻿﻿lock_frame（WGC 颜色 + marker 配对）CP2077 测试步骤
=====================================================

已部署内容
  - 游戏目录 dxgi.dll / nvngx_dlssg.dll      = 新版 fakerFG（present 前画四角 marker）
  - 游戏目录 xess_mfg_producer.dll            = 新版 producer（ColourStream=0, StreamPercent=150）
  - 游戏目录 fakerFG.ini                      = 只改了 ColourStream=0、StreamPercent/Mv/Depth=150
  - lock_frame.exe 默认 --upsample            = 把 150% 的 MV/depth 重建到输入画面尺寸再给 XeFG
  - 游戏目录 lock_frame\                      = lock_frame.exe / lock_frame_ui.exe + 运行库
  - 备份目录: _lock_frame_backup_20261115_132437\

执行步骤
  1. 启动 Cyberpunk 2077。
  2. 游戏设置里开启 DLSS（必须是 DLSS，不是 TAA/TSR）——日志出现
     "sr: upscaler lane ..." / "xefg: upscaler Evaluates ..." 才说明输入链路通了。
  3. 窗口/无边框全屏，分辨率与桌面一致（日志里是 1920x1080 -> 3840x2160）。
  4. 把游戏锁到 30 fps（用 30x4）或 40 fps（用 40x3）：RTSS 或游戏内限制器。
     本版本不在消费端丢帧，输入节拍由游戏侧锁帧提供。
  5. 运行 lock_frame\lock_frame_ui.exe：
       - 选 Cyberpunk 窗口
       - 模式选「锁帧 30 x 4」或「锁帧 40 x 3」
       - 点启动
     或者直接运行 lock_frame\run_30x4.bat / run_40x3.bat（已带 --game Cyberpunk2077.exe）。

看哪些日志
  游戏目录 Cyberpunk2077_fakerFG.log：
    - "marker draw: ... code=0x..."         marker 正在画（每 240 帧一行）
    - "producer: ...xess_mfg_producer.dll -> start=0 (api v...)"  producer 已加载
    - "publish #1 ..."                       开始发布 MV/depth
    - 如果还是 "producer: ... not present"   说明 DLL 没放对位置
  lock_frame 输出：
    - UI 启动：lock_frame\lock_frame_ui_HHMMSS.txt
    - run bat：lock_frame\lock_frame_30x4.log / lock_frame_40x3.log
    正常应有：
      [lock] marker: seq12=... ms12=... code=0x...
      [lock] marker pair: WGC ... -> slot ... (frame_id=...)
      [lock] pair: exact=40 no_slot=0 ... dup=0 ... lag(avg=..., max=...)
      dup 是 loading/menu/pause 的重复帧（按 seq12 去重），不参与命中率；
      正常游戏中的 active 窗口应只剩 exact 和少量 no_slot。
    - exact 应接近 total；no_slot/unreadable 多说明 marker 被 HUD 挡住或画面被缩放
    - lag.max + 2 必须小于 4（4 个槽）

注意
  - 不要同时运行旧的 xess_mfg_consumer.exe；同一时间只跑 lock_frame.exe。
  - 方案里有两个 A/B 文件，默认都不要放：
      marker_disable.on       （会让 fakerFG 不画 marker，配对必然失败）
      marker_repair_off.on    （会让四角 marker 留在画面上）
  - 面板需要 120 Hz（30x4 / 40x3 都是 120 fps 输出）。

回滚
  把备份目录里的 dxgi.dll.pre_lock_frame / nvngx_dlssg.dll.pre_lock_frame /
  fakerFG.ini.pre_lock_frame 覆盖回游戏目录，并删除 xess_mfg_producer.dll 与
  lock_frame\ 目录即可恢复到部署前状态。
