## 这轮做的事

每帧流程：

```
NGX EvaluateFeature 钩子   → 记住 MV / 深度 / jitter（2560×1440）
reshade_begin_effects      → 在游戏自己的命令列表上：
                              barrier(已知状态 → copy_source)
                              CopyResource(游戏纹理 → 邮箱源纹理)
                              barrier(copy_source → 原状态)
reshade_present            → 在游戏队列上 Signal fence（此时帧已提交）
                              mailbox.publish_after() 搬到共享槽
                              mailbox.consume()       AMD 侧取走（M4 的占位）
```

关键设计：
- **障碍转换用游戏自己的命令列表**，所以顺序和状态都归游戏管，我们只是插了一段再原样还原；
- **状态靠 `addon_event::barrier` 跟踪**，没跟踪到的资源**跳过而不是瞎猜**（猜错会 GPU 挂起）；
- **publish 排在游戏队列 fence 之后**，保证搬的是已经算完的数据。
